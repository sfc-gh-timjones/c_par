PAR — Constellation Schema

CUSTOMER_DEMOS.PAR · 1 shared dimension · 5 fact tables

Constellation schema: a single dimension table (PAR_DISTRICTS) shared across multiple fact tables. Each fact table joins to the dimension via DISTRICT_ID (N:1). This is distinct from a star schema, where one central fact table is surrounded by dimensions.
